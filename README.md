# Practical Deep Learning for Coders

*A learning journey through deep learning with fastai and PyTorch.*

This repository documents my progress through **Practical Deep Learning for Coders**, following Jeremy Howard's video course and the book *Deep Learning for Coders with fastai and PyTorch* by Jeremy Howard and Sylvain Gugger.

I'm using this repository to practice what I learn, experiment with different models and datasets, and build a stronger understanding of deep learning fundamentals.


## What You'll Find Here

- **Course exercises:** Jupyter notebooks based on the book and video lessons.
- **Hands-on experiments:** Small modifications and additional tests to explore how models behave.
- **Learning notes:** Explanations of important concepts, challenges, and things I've learned along the way.

## Learning Goals

Through this course, I want to:

- Understand the fundamentals of neural networks and deep learning.
- Gain hands-on experience with fastai and PyTorch.
- Learn how to train, evaluate, and improve machine learning models.
- Develop the confidence to apply what I've learned to independent projects.
